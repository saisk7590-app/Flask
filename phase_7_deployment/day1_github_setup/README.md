# Day 1 — GitHub & Deployment Setup

## 📌 Overview

This folder contains the learning material and preparation work for **Phase 7 — Deployment & Production, Day 1**.

The purpose of Day 1 is to prepare a Flask backend project for deployment and understand the basic Git and GitHub workflow.

---

## 🎯 Objectives

By the end of Day 1, you should understand:

* Git fundamentals
* GitHub repositories
* Local vs production environments
* `requirements.txt`
* `.gitignore`
* README documentation
* Basic Git workflow
* Preparing a Flask project for deployment

---

## 📚 Topics Covered

### Git

Version control system used to track changes in source code.

### GitHub

Online platform for hosting Git repositories.

### requirements.txt

Defines the Python dependencies required by the project.

### .gitignore

Prevents unnecessary or sensitive files from being tracked by Git.

### README.md

Provides documentation about the project.

### Production Preparation

Preparing the Flask application and project structure before deployment.

---

## 🔄 Basic Git Workflow

```text
Modify Code
    ↓
git status
    ↓
git add .
    ↓
git commit
    ↓
git push
    ↓
GitHub
```
